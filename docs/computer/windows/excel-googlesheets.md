- Dấu phân cách công thức phụ thuộc vào Locale của file

Google Sheets không cố định dùng dấu , hay ;
👉 Nó phụ thuộc vào quốc gia (Locale) được chọn trong File settings.

Quy tắc chung:
Locale	Dấu phân cách tham số
US, UK	, (comma)
Việt Nam, EU (Đức, Pháp, v.v.)	; (semicolon)
